# Customer-Segmentation-Project
Customer Segmentation using K-Means clustering with EDA and business insights

## Project Overview
This project segments customers into groups using K-Means clustering.

## Dataset Features
- Annual Income
- Spending Score
- Age
- Savings
- Online Spend

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
- EDA
- Data Cleaning
- Feature Scaling
- Elbow Method
- Silhouette Score
- K-Means Clustering
- Business Insights

## Results
Customers were divided into meaningful groups and marketing strategies were suggested.
